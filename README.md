# Memorias_del_Conflicto

![Memoria Viva Hero](https://images.unsplash.com/photo-1583095125964-b8166bc2fb5c?q=80&w=1920&auto=format&fit=crop)

Un recorrido por Pensilvania, al corregimiento de Arboleda y a la Vereda La Iguana para comprender el conflicto, sanar las heridas y construir la paz en nuestro territorio. 

Este proyecto es una aplicación web interactiva desarrollada como apoyo a la sustentación argumentativa del conflicto y la memoria histórica, con el objetivo de escuchar las voces de quienes vivieron la guerra en carne propia.

## 📌 Características

- Diseño completamente responsivo.
- Sistema de testimonios en video integrados sin cookies (privacidad en línea).
- Pestañas interactivas para análisis de la construcción de paz.
- Animaciones de revelado al hacer scroll.
- Efectos de interfaz modernos utilizando Tailwind CSS.

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Semántico)
- **Tailwind CSS** (Vía CDN para estilos rápidos y responsivos)
- **JavaScript Vanilla** (Para animaciones y lógica de interfaz)
- **FontAwesome** (Iconografía)
- **Google Fonts** (Merriweather, Open Sans)

## 🚀 Despliegue en Vercel

Este proyecto está optimizado y listo para ser desplegado en [Vercel](https://vercel.com/) sin necesidad de configuración adicional (Zero-Config), dado que es un sitio estático (`index.html`).

### Pasos para el despliegue:

1. Sube este repositorio a tu cuenta de **GitHub**.
2. Inicia sesión en **Vercel** usando GitHub.
3. Haz clic en **"Add New..."** -> **"Project"**.
4. Importa el repositorio de **Memoria Viva** desde la lista.
5. Vercel detectará automáticamente que es un proyecto estático. Haz clic en **Deploy**.
6. ¡Listo! Tendrás un enlace público en segundos.
